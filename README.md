# cos10026-applied-web-project
Basket Digital - Recruitment Web Platform

A static e-commerce recruitment website built with semantic HTML5 and CSS3 for COS10026 Group G05.

Project Scenario
Basket Digital is an E-Commerce & Digital Retail Platform expanding its technical and user experience teams to enhance customer-facing websites, product listings, and online application workflows.
